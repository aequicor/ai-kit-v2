# bundle.json

Манифест бандла AI-Kit. Лежит в корне бандла (папки или zip-архива). Описывает метаданные, список поддерживаемых агентов и параметры, которые CLI спрашивает у пользователя при установке.

## Пример

```json
{
  "schemaVersion": 1,

  "name": "my-bundle",
  "version": "1.2.0",
  "description": "Полное описание бандла",
  "author": "Имя Автора <email@example.com>",
  "license": "MIT",

  "targets": ["claude-code", "opencode"],

  "inputs": [
    {
      "id": "github-mcp",
      "type": "boolean",
      "title": "Подключить GitHub MCP?",
      "description": "Включать, если проект хостится на GitHub (есть удалённый origin на github.com). Даёт агенту доступ к issues, PR и code search через GitHub MCP.",
      "default": true
    },
    {
      "id": "skills",
      "type": "multiselect",
      "title": "Какие скилы установить?",
      "options": ["review", "security-review", "init"],
      "default": ["review"]
    },
    {
      "id": "model",
      "type": "select",
      "title": "Модель по умолчанию",
      "options": ["opus", "sonnet", "haiku"],
      "default": "sonnet"
    },
    {
      "id": "project-name",
      "type": "string",
      "title": "Имя проекта",
      "default": "${cwd.basename}",
      "required": false
    },
    {
      "id": "max-tokens",
      "type": "int",
      "title": "Лимит токенов на ответ",
      "default": 4096,
      "min": 1,
      "max": 200000
    },
    {
      "id": "temperature",
      "type": "double",
      "title": "Temperature модели",
      "default": 0.7,
      "min": 0.0,
      "max": 2.0
    }
  ]
}
```

## Поля верхнего уровня

| Поле | Обяз. | Назначение |
|---|---|---|
| `schemaVersion` | да | Версия формата `bundle.json`. Увеличивается при breaking changes структуры манифеста |
| `name` | да | Уникальный идентификатор бандла (kebab-case) |
| `version` | да | SemVer бандла |
| `description` | да | Одна строка, что делает бандл |
| `author` | нет | Автор |
| `license` | нет | SPDX-идентификатор лицензии (`MIT`, `Apache-2.0`, …) |
| `targets` | да | Список поддерживаемых агентов. Для каждого id обязана существовать одноимённая папка в корне бандла |
| `inputs` | нет | Параметры, которые CLI спрашивает у пользователя при установке. Отсутствие или пустой массив = бандл без параметров |

## Поля `input`

| Поле | Обяз. | Применимо к | Назначение |
|---|---|---|---|
| `id` | да | всем | Идентификатор параметра. Для `boolean`, `select` и `multiselect` совпадает с именем папки-компонента внутри агента (`<agent>/<id>/…`) |
| `type` | да | всем | Один из: `boolean`, `select`, `multiselect`, `string`, `int`, `double` |
| `title` | да | всем | Короткий текст вопроса при интерактивном опросе |
| `description` | нет | всем | Развёрнутое пояснение: когда параметр стоит включать/какое значение выбрать, какие предпосылки в проекте. Показывается человеку под `title` и используется ИИ-агентом при неинтерактивной установке для автоматического выбора значения |
| `default` | нет | всем | Значение по умолчанию. Для `string` поддерживает плейсхолдеры вида `${cwd.basename}` |
| `required` | нет | `string`, `int`, `double` | Если `true`, пустое значение не принимается |
| `options` | да | `select`, `multiselect` | Допустимые значения |
| `min` | нет | `int`, `double` | Минимально допустимое значение (включительно) |
| `max` | нет | `int`, `double` | Максимально допустимое значение (включительно) |

## Типы `input` и их влияние на генерацию

Связь между `inputs` и файлами строится по конвенции, без отдельной секции `components`.

### `boolean`

`id` совпадает с именем папки-компонента внутри каждой папки агента. Если ответ `true` — содержимое папки применяется; если `false` — пропускается.

```
inputs: { "id": "github-mcp", "type": "boolean" }

claude/github-mcp/…       ← применяется если true
opencode/github-mcp/…     ← применяется если true
```

### `select`

Выбор ровно одного значения из `options`. `id` = имя категории (папка внутри агента), значения = подпапки внутри неё. Применяется только выбранная подпапка.

```
inputs: { "id": "model", "type": "select", "options": ["opus", "sonnet", "haiku"] }

claude/model/opus/…       ← применяется если выбран "opus"
claude/model/sonnet/…     ← применяется если выбран "sonnet"
claude/model/haiku/…      ← применяется если выбран "haiku"
```

### `multiselect`

Выбор нескольких значений из `options`. `id` = имя категории (папка внутри агента), значения = подпапки внутри неё. Применяются только выбранные подпапки.

```
inputs: { "id": "skills", "type": "multiselect", "options": ["review", "init"] }

claude/skills/review/…    ← применяется если "review" в ответе
claude/skills/init/…      ← применяется если "init" в ответе
```

### `string`

Не управляет включением файлов. Подставляется в содержимое шаблонов через `{{inputs.<id>}}`.

### `int` / `double`

Числовые параметры. Не управляют включением файлов — подставляются в шаблоны через `{{inputs.<id>}}`. `int` принимает только целые числа, `double` — числа с плавающей точкой. Опциональные поля `min`/`max` задают допустимый диапазон (включительно).

```
inputs: { "id": "temperature", "type": "double", "default": 0.7, "min": 0.0, "max": 2.0 }
```

## Раскладка папки агента

Каждая папка-компонент внутри агента имеет фиксированную внутреннюю структуру. CLI знает, как разложить её содержимое в каноническую конфигурацию агента (мерджит JSON-файлы, копирует команды/скилы и т. д.). Конкретный маппинг определяется для каждого агента отдельно и описывается в спецификации поддержки агента.

## Валидация

- Все id из `targets` обязаны иметь одноимённую папку в корне бандла.
- Все id из `inputs` уникальны.
- Для `select` `default` (если задан) должен входить в `options`.
- Для `multiselect` все элементы `default` должны входить в `options`.
- Для `boolean`/`select`/`multiselect` id должны соответствовать существующим папкам-компонентам хотя бы у одного из агентов; иначе input ни на что не влияет.
- Для `int`/`double`: если заданы `min`/`max`, то `min ≤ default ≤ max`; для `int` значения `default`/`min`/`max` должны быть целыми.
